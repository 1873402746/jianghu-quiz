# 古风江湖身份牌 · H5 答题应用

一个零依赖、零构建的移动端答题 H5。**32 题题库，每轮随机抽取 16 题，同一轮内绝不重复**；答完提交后给出身份牌与三维得分反馈。

**在线地址**：https://1873402746.github.io/jianghu-quiz/

---

## 一、玩法与规则

| 项目 | 说明 |
|---|---|
| 题库总量 | 32 题 |
| 每轮抽题 | 16 题，Fisher–Yates 洗牌后截取，天然不重复 |
| 选项 | 每题 3 个，选项顺序也会打乱（`meta.js` 可关） |
| 计分维度 | 义气 / 机敏 / 耐性（三维，隐藏计分） |
| 结果 | 6 种身份之一，由三维排名唯一决定 |
| 流程 | 首屏 → 逐题作答 → 提交 → 结算动效 → 结果页（身份牌 + 契合度 + 三维条 + 同门比例） |

### 为什么三维排名恰好是 6 种身份

三个维度共有 6 种排名组合，一一对应 6 种身份，因此**不需要额外的"岔路题"**，随机抽 16 题也不会破坏判定逻辑：

| 排名 | 身份 | 签文 |
|---|---|---|
| 义 > 机 > 耐 | 侠客 | 先救人，再讲理 |
| 义 > 耐 > 机 | 说书人 | 故事讲完，人就散了，我还记得 |
| 机 > 义 > 耐 | 信使 | 话到我这里，就不会丢 |
| 机 > 耐 > 义 | 谋士 | 账要算，人也要算 |
| 耐 > 义 > 机 | 守夜人 | 别人睡了，我醒着 |
| 耐 > 机 > 义 | 账房先生 | 一文钱也要算得清，一顿亏也不肯吃 |

### 两条必须守住的题库约束

改题库时如果不满足这两条，结果会失真（实测踩过坑）：

1. **每题三个选项的分值之和恒为 3** → 16 题总分恒为 48，三维百分比可直接横向比较且必然合计 100。
2. **每题三个维度各自的和恒为 3/3/3** → 任取 16 题的子集三维权重都完全均衡，结果不被题库偏向带跑。

更关键的是**选项配比**：如果选项分值总让某一维度恰好为 0，该维度就永远排不进第二，对应身份会变成"死内容"。早期版本配比失调时，6 个身份里有 2 个（信使、守夜人）几乎抽不到。现在题库按 6 种模式精确配比，使每个维度的"次修"在另外两维上均为 **11 : 11 : 10**。详见 `assets/data/questions.js` 顶部的注释表。

## 二、目录结构

```
jianghu-quiz/
├── index.html                  # 页面骨架（四屏）
├── assets/
│   ├── skin.css                # 皮肤 A · 宣纸工笔（CSS 变量 token）
│   ├── engine.js               # 引擎层：抽题 / 计分 / 渲染 / 动效 / 音效
│   ├── art.js                  # 8 张场景线描（占位素材，可整体替换）
│   └── data/                   # 配置层 —— 换一期内容只动这里
│       ├── meta.js             # 标题、副标、抽题数、是否打乱选项、免责声明
│       ├── questions.js        # 32 题题库
│       └── results.js          # 6 种身份：签文、备选签文、侧写、同门比例
├── tools/
│   ├── verify.js               # 自测：抽题/计分/流程/多宽度，并出图
│   └── shots.js                # 自测：把 8 种插画的题目页拼成一张对照图
└── preview/                    # 自测产出的截图
```

**引擎层与配置层严格分离**：新增一期只改 `assets/data/`，`engine.js` 与 `skin.css` 不需要动。

## 三、本地运行

页面用 `<script src>` 加载本地脚本，**双击 `index.html` 即可运行**，不需要起服务、不需要联网、没有任何外部资源请求。

## 四、自测

需要本机 Chrome 与 `puppeteer-core`（仅开发期使用，不参与线上页面）：

```bash
NODE_PATH=<puppeteer-core 所在 node_modules> node tools/verify.js
```

`tools/verify.js` 会检查：

- **抽题**：2000 轮，断言长度、轮内去重、确实洗过牌、题库全覆盖、首题分布均匀
- **计分**：选项分值和、每题三维和 3/3/3、6 种排名组合全部有身份对应
- **区分度**：三种偏好类型的模拟用户各跑 1500 轮，断言 6 个身份都能被命中
- **流程**：首屏 → 逐题真实点击答完 16 题 → 未答完提交被拦截 → 补答 → 提交 → 结算 → 结果页
- **适配**：320 / 360 / 390 / 414 / 480 五个宽度下横向溢出必须为 0
- **错误**：收集并打印所有 console error 与 pageerror，必须为空

`tools/shots.js` 用于出图，便于人工核对视觉。

## 五、替换插画

`assets/art.js` 里的 8 张线描是**占位示意**（`kezhan` 客栈 / `yizhan` 驿站 / `shanlu` 山路 / `dukou` 渡口 / `zhangfang` 账房 / `shiji` 市集 / `yexun` 夜巡 / `shufang` 书房）。

替换方法：把每张图的内部内容换成 `<img>` 或新的 SVG 字符串即可，`viewBox` 统一为 `300 × 132`（横版）。题库里通过 `art` 字段引用，**不需要改引擎与题库结构**。

## 六、合规说明

- **零信息采集**：无手机号、无位置、无通讯录、无登录、无第三方统计脚本。
- **无诱导分享**：不做"分享解锁结果"，分享只做"长按保存页面"。
- **免责声明**：首屏与结果页各一处，色值 `#9C9188`（非隐藏式浅灰），字号 ≥ 10.5px。
- **无绝对化用词**：不使用"最 / 第一 / 唯一 / 绝对 / 100%"；得分上限收敛到 98。
- **选项立场**：三个选项不设道德高低，只区分倾向。
- **素材版权**：插画全部为内联 SVG 绘制，无明星肖像、无品牌标识。

---

## 七、技术约定

- 原生 HTML + CSS + JS，**零框架、零构建、零依赖**
- 基准尺寸 375 × 812，支持 `env(safe-area-inset-*)` 安全区
- 动效只用 `transform` / `opacity`，单次动画 ≤ 400ms，尊重 `prefers-reduced-motion`
- 音效由 WebAudio 现场合成，**无音频文件**，默认静音，右上角常驻开关
